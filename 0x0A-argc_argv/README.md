# 0x0A - Command Line Arguments (argc & argv)

This project introduces command-line arguments in C: how a program receives
inputs from the shell, how to count them, and how to use them to drive
the program's behavior.

## Tasks

| Task | File | Description |
|------|------|-------------|
| 0 | `0-whatsmyname.c` | Prints the program's own name |
| 1 | `1-args.c` | Prints the number of arguments (excluding the program name) |
| 2 | `2-args.c` | Prints every argument, one per line |
| 3 | `3-mul.c` | Multiplies two numbers from the command line |
| 4 | `4-add.c` | Adds positive numbers, error on non-digits |
| 5 | `100-change.c` | Prints minimum coins needed for change |

## How to compile

Every program is compiled with the strict flags:

gcc -Wall -Wextra -Werror -pedantic -std=gnu89 file.c -o output
