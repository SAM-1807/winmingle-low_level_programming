# 0x10 - Variadic Functions

This project introduces variadic functions in C, using `<stdarg.h>` to handle an unknown number of arguments.

## Learning Objectives

- What variadic functions are
- How to use `va_start`, `va_arg`, and `va_end`
- Why and how the `const` type qualifier is used

## Tasks

| Task | File | Description |
|------|------|-------------|
| 0 | `0-sum_them_all.c` | Returns the sum of all parameters |
| 1 | `1-print_numbers.c` | Prints numbers with a given separator |
| 2 | `2-print_strings.c` | Prints strings with a given separator |
| 3 | `3-print_all.c` | Prints any argument type based on a format string |

## Compilation

All files are compiled on Ubuntu 20.04 LTS using:
`gcc -Wall -Werror -Wextra -pedantic -std=gnu89`
