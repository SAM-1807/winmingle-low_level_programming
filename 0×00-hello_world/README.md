# 0x00 - Hello, World

This project introduces the C programming language, its compilation process, and basic syntax.

## Topics covered

- Writing simple C programs
- Compilation stages (preprocessor, compiler, assembler, linker)
- Using `puts` and `printf`
- Understanding `putchar` and `_putchar`
- Working with ASCII
- Compiling with strict flags (`-Wall -Werror -Wextra -pedantic -std=gnu89`)

## Tasks

- `0-preprocessor` - Script to run preprocessor
- `1-compiler` - Script to compile without linking
- `2-assembler` - Script to generate assembly code
- `3-name` - Script to compile and name executable
- `4-puts.c` - Print using `puts`
- `5-printf.c` - Print using `printf`
- `6-size.c` - Print sizes of data types
- `100-intel` - Generate Intel syntax assembly
- `101-quote.c` - Print to stderr and return 1

## Compilation

All C files compiled with:
`gcc -Wall -Werror -Wextra -pedantic -std=gnu89`
