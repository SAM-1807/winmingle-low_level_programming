# 0x06 - More pointers, arrays and strings

This project covers advanced string manipulation using pointers and arrays.

## Learning objectives

    - Pointers and arrays
- String manipulation (concat, copy, compare)
    - Array reversal
- Character transformation (uppercase, leet, ROT13)
    - Printing integers with `_putchar`

## Requirements

    - Compiled with `gcc -Wall -Werror -Wextra -pedantic -std=gnu89`
    - No standard library functions
    - Only `_putchar` allowed for output
    - No global variables
    - Max 5 functions per file
    - Header file: `main.h`
