# 0x0E - Structures, typedef

This project introduces C structures and the `typedef` keyword.

## Learning Objectives

- What structures are, when and why to use them
- How to use `typedef`

## Tasks

| Task | File | Description |
|------|------|-------------|
| 0 | `dog.h` | Defines `struct dog` and `typedef dog_t` |
| 1 | `1-init_dog.c` | Initializes a `struct dog` |
| 2 | `2-print_dog.c` | Prints a `struct dog` |
| 4 | `4-new_dog.c` | Allocates and creates a new dog |
| 5 | `5-free_dog.c` | Frees a dog created by `new_dog` |

## Compilation

All files compiled with:
`gcc -Wall -Werror -Wextra -pedantic -std=gnu89`
