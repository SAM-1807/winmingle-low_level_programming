# 0x05 - Pointers, arrays, strings

This project introduces pointers, arrays, and string manipulation in C.

## Learning objectives

- What are pointers and how to use them
- What are arrays and how to use them
- Differences between pointers and arrays
- How to use strings and manipulate them
- Scope of variables

## Requirements

- Allowed editors: `vi`, `vim`, `emacs`
- Compilation: `gcc -Wall -Werror -Wextra -pedantic -std=gnu89`
- Every file must end with a new line
- No global variables
- Max 5 functions per file
- No standard library functions (`printf`, `puts`, etc.) — only `_putchar`
- Header file: `main.h`

## Tasks

0. `reset_to_98` – updates value to 98 using pointer
1. `swap_int` – swaps values of two integers
2. `_strlen` – returns length of a string
3. `_puts` – prints a string
4. `print_rev` – prints a string in reverse
5. `rev_string` – reverses a string
6. `puts2` – prints every other character of a string
7. `puts_half` – prints half of a string
8. `print_array` – prints n elements of an array
9. `_strcpy` – copies a string
10. `_atoi` – converts a string to an integer
11. `101-keygen.c` – generates random valid passwords
