# 0x0D - Preprocessor

This project covers C preprocessor directives: object-like macros,
function-like macros, include guards, and predefined macros.

## Tasks

| Task | File | Description |
|------|------|-------------|
| 0 | `0-object_like_macro.h` | Defines SIZE as 1024 |
| 1 | `1-pi.h` | Defines PI as 3.14159265359 |
| 2 | `2-main.c` | Prints the source file name |
| 3 | `3-function_like_macro.h` | ABS macro |
| 4 | `4-sum.h` | SUM macro |

## Compilation

gcc -Wall -Werror -Wextra -pedantic -std=gnu89 file.c -o output
