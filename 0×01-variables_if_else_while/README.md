# 0x01 - Variables, if, else, while

This project covers:
- Arithmetic operators
- Logical (boolean) operators
- Relational operators
- TRUE and FALSE values in C
- if and if...else statements
- while loops
- ASCII character set
- Comments and variable declaration
- Printing variable values using printf

## Tasks

- 0-positive_or_negative.c - Random number positivity check
- 1-last_digit.c - Extract last digit and describe it
- 2-print_alphabet.c - Print lowercase alphabet using putchar
- 3-print_alphabets.c - Print lowercase then uppercase alphabet
- 4-print_alphabt.c - Print lowercase alphabet except 'e' and 'q'
- 5-print_numbers.c - Print single-digit numbers 0-9
- 6-print_numberz.c - Print numbers 0-9 using only int variables
- 7-print_tebahpla.c - Print lowercase alphabet in reverse
- 8-print_base16.c - Print hexadecimal digits
- 9-print_comb.c - Print combinations of single-digit numbers
- 100-print_comb3.c - Combinations of two different digits
- 101-print_comb4.c - Combinations of three different digits
- 102-print_comb5.c - Combinations of two two-digit numbers

## Compilation

All files compiled with:
`gcc -Wall -Werror -Wextra -pedantic -std=gnu89`
