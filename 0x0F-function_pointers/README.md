# 0x0F - Function pointers

This project covers function pointers, passing functions as arguments,
and using arrays of structs to map strings to functions.

## Tasks

| Task | File | Description |
|------|------|-------------|
| 0 | `0-print_name.c` | Prints a name via a function pointer |
| 1 | `1-array_iterator.c` | Applies a function to each array element |
| 2 | `2-int_index.c` | Finds index of first match |
| 3 | `3-calc.h`, `3-op_functions.c`, `3-get_op_func.c`, `3-main.c` | Calculator using function pointers |
| 4 | `100-main_opcodes.c` | Prints the opcodes of its own main |

## Compilation

gcc -Wall -Werror -Wextra -pedantic -std=gnu89 file.c -o output
