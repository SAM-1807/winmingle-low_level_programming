# 0x03 - Debugging

This project focuses on identifying, analyzing, and fixing bugs in C programs.

## Learning Objectives

- Explain what debugging means
- Identify and fix common coding errors manually
- Read and interpret compiler error messages
- Apply logical debugging using test files

## Tasks

### Task 0: Multiple mains
- `0-main.c` - Test file that calls `positive_or_negative(0)`
- `main.h` - Header file with function prototype

### Task 1: Like, comment, subscribe
- `1-main.c` - Fix infinite loop by commenting out the problematic line

### Task 2: 0 > 972?
- `2-largest_number.c` - Fix function to return largest of three integers

### Task 3: Leap Year
- `3-print_remaining_days.c` - Fix leap year calculation logic
- `3-convert_day.c` - Convert month/day to day of year

## Compilation

All files compiled with:
`gcc -Wall -Werror -Wextra -pedantic -std=gnu89`
