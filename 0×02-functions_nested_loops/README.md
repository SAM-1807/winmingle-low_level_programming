# 0x02 - Functions, nested loops

This project introduces functions, nested loops, and header files in C.

## Topics covered

- What are nested loops and how to use them
- What is a function and how to use functions
- Difference between declaration and definition of a function
- What is a prototype
- Scope of variables
- Header files and how to use them with `#include`
- GCC flags: `-Wall -Werror -Wextra -pedantic -std=gnu89`

## Tasks

### Mandatory

- `0-putchar.c` - Program that prints `_putchar`
- `1-alphabet.c` - Function that prints lowercase alphabet
- `2-print_alphabet_x10.c` - Function that prints alphabet 10 times
- `3-islower.c` - Function that checks for lowercase character
- `4-isalpha.c` - Function that checks for alphabetic character
- `5-sign.c` - Function that prints sign of a number
- `6-abs.c` - Function that computes absolute value
- `7-print_last_digit.c` - Function that prints last digit
- `8-24_hours.c` - Function that prints every minute of the day
- `9-times_table.c` - Function that prints 9 times table
- `10-add.c` - Function that adds two integers
- `11-print_to_98.c` - Function that prints numbers from n to 98

### Advanced

- `100-times_table.c` - Function that prints n times table
- `101-natural.c` - Sum of multiples of 3 or 5 below 1024
- `102-fibonacci.c` - First 50 Fibonacci numbers
- `103-fibonacci.c` - Sum of even Fibonacci terms below 4,000,000
- `104-fibonacci.c` - First 98 Fibonacci numbers (with overflow)

## Compilation

All files compiled with:
`gcc -Wall -Werror -Wextra -pedantic -std=gnu89`

## Header file

- `main.h` - Contains prototypes for all functions and `int _putchar(char c);`
